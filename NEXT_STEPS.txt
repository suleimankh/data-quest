STEP 3: Validate the DAB Configuration
═══════════════════════════════════════════════════════════════════════════════

From your local machine (after installing Databricks CLI):

    # Authenticate
    databricks auth login --host https://dbc-c2ce80d3-dded.cloud.databricks.com
    
    # Validate production configuration
    cd /path/to/local/data-quest
    databricks bundle validate -t prod


STEP 4: Deploy to Production
═══════════════════════════════════════════════════════════════════════════════

    databricks bundle deploy -t prod

This will create:
  ✓ bls_pipeline_prod → rearc.bls
  ✓ datausa_pipeline_prod → rearc.datausa  
  ✓ analytics_pipeline_prod → rearc_analytics.population_analytics
  ✓ population_orchestration_pipeline_prod (orchestration job)


STEP 5: Run the Orchestration Job
═══════════════════════════════════════════════════════════════════════════════

    databricks bundle run population_orchestration -t prod

Or in Databricks UI:
  Workflows → Jobs → population_orchestration_pipeline_prod → Run now


STEP 6 (Optional): Set Up GitHub Actions CI/CD
═══════════════════════════════════════════════════════════════════════════════

1. Generate Databricks token:
   Databricks UI → User Settings → Developer → Access tokens

2. Add GitHub secrets:
   GitHub repo → Settings → Secrets and variables → Actions
   
   Add:
   - DATABRICKS_HOST = https://dbc-c2ce80d3-dded.cloud.databricks.com
   - DATABRICKS_TOKEN = [your token]

3. Future pushes to 'main' will auto-deploy to production
